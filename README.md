# odin-landing-page-project
A responsive-ready marketing landing page built with semantic HTML5 and CSS Flexbox, based on The Odin Project's Foundations landing page assignment.

# Overview
This project recreates a common landing page layout consisting of five sections:
1. Header — logo and navigation links
   Hero — headline, subtext, call-to-action button, and image
2. Info — section heading with four feature cards
3. Testimonial — customer quote with attribution
4. CTA banner — secondary call-to-action
5. Footer — copyright notice

# Built With
- HTML5 — semantic elements (header, nav, section, blockquote, cite, footer)
- CSS3 — Flexbox for all layout, no CSS frameworks
- Google Fonts — Roboto

# Key Concepts Practiced
- Flexbox layout: justify-content, align-items, flex-grow/flex-shrink/flex-basis, gap
- Semantic HTML structure and accessible alt text conventions
- Nested flex containers (flex properties don't cascade to grandchildren)
- box-sizing: border-box as a global reset
- object-fit: cover for consistent image cropping
- Structuring a project for section-by-section styling
